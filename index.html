Projeto principal

SOL+

Aplicativo Android nativo e offline para organizar lembretes e registrar uma rotina de cuidados com medicamentos.

Código-fonte Documentação

Imagens geradas em emulador com dados de demonstração. Dados reais, backups e bancos não fazem parte do repositório.

Problema

Organizar a rotina de cuidados com medicamentos de forma confiável, offline e sem depender de conta em nuvem. O aplicativo precisava funcionar em dispositivos simples, respeitar a privacidade e manter um histórico que permitisse corrigir registros equivocados.

Solução

Aplicativo Android nativo com três lembretes diários configuráveis, confirmações independentes por cuidado, opções de confirmar, adiar, registrar incerteza e corrigir o histórico, além de calendário e trilha de correções.

  • Armazenamento 100% local — sem conta, sem API remota
  • Notificações locais com reagendamento após reinicialização
  • Tela de diagnóstico para permissões e restrições de bateria

Tecnologias

  • Kotlin 2.0
  • Jetpack Compose
  • Material 3
  • Room
  • DataStore
  • AlarmManager
  • Coroutines / Flow
  • JUnit 4
  • Espresso
  • Compose UI Test
  • GitHub Actions

Principais decisões

  • Arquitetura próxima de MVVM com ViewModels, coroutines e Flow — separação de responsabilidades mesmo em módulo único
  • Room + DataStore para persistência e preferências — sem sincronização externa
  • AlarmManager para notificações locais — com lógica de reagendamento após reinicialização
  • Restauração de backup desativada na interface por segurança, evitando dados de outros dispositivos

Testes e automação

Testes, lint e build automatizados com GitHub Actions a cada push na branch main. Verificação reproduzida documentada em docs/TESTING.md.

Limitações conhecidas

  • Rotina e textos desenhados para um caso de uso específico, não prescrições gerais
  • Sem sincronização em nuvem nem recuperação automática após desinstalação
  • Variante release ainda sem assinatura de distribuição
  • Políticas de bateria de fabricantes podem atrasar notificações
  • Acessibilidade com TalkBack e escala máxima de fonte ainda pendente de validação em dispositivo físico
  • Projeto educacional: não substitui orientação médica, cuidador ou dispositivo clínico
