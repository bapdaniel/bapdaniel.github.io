## 3. Descrição do SOL+ para a seção "Projetos"

**Nome do projeto:** SOL+

**Período:** Set 2026 – presente

**Descrição:**
```
Aplicativo Android nativo e offline para organizar lembretes e registrar
uma rotina de cuidados com medicamentos.

Implementei os três lembretes diários configuráveis, confirmações independentes
por cuidado, opções de confirmar, adiar, registrar incerteza e corrigir o histórico,
calendário e histórico com trilha de correções.

Tecnologias: Kotlin 2.0, Jetpack Compose, Material 3, Room, DataStore, AlarmManager,
Coroutines/Flow, JUnit 4, Espresso, Compose UI Test e GitHub Actions.

O projeto contém 28 testes JVM e 10 testes instrumentados. Testes, lint e build
são automatizados via GitHub Actions a cada push.

Projeto educacional. Primeiro projeto acadêmico em ADS.
```

**Link do projeto:** https://github.com/bapdaniel/solplus-android
